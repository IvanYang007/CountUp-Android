How Apple creates powerful 3D physical depth without relying on big blurry shadows:

1. Apple Tactile ★ Recommended

Top specular highlight + subtle satin surface gradient + micro contact shadow. Tangible physical tile feel.

2. Ceramic Bevel Pure White

Solid white card with dual top/bottom physical chamfer ridges + crisp 2dp base shadow.

3. Embossed Paper Crisp Rim

Double-ridge paper border with high-contrast hairline perimeter. Zero diffuse blur.

4. Diffuse Float Legacy Shadow

Larger 6dp drop shadow without surface specular gradient. (Notice the difference in 3D solidity).

📐 The 3 Anatomy Pillars of Apple 3D Tactility

1. Top Specular Sheen

A crisp 1px pure-white reflection along the top edge simulates overhead ambient lighting striking a physical rounded bevel.

2. Convex Surface Gradient

Transitioning from pure white #FFFFFF (top) to warm satin #FAF6EE (bottom) creates optical curvature across the face.

3. Sharp Contact Occlusion

Instead of a fuzzy 14dp blur, a tight 2dp–3dp shadow with 8% ink opacity defines the card's physical ground contact without edge smudging.

// In CountUpContent.kt -> ItemCard()
val cardShape = RoundedCornerShape(20.dp)
val surfaceBrush = remember {
    Brush.verticalGradient(
        colors = listOf(
            Color.White,            // Top specular shine
            Color(0xFFFAF5EE),      // Bottom warm satin paper
        )
    )
}
val borderBrush = remember {
    Brush.verticalGradient(
        colors = listOf(
            Color.White.copy(alpha = 0.90f), // Top crisp highlight
            Color(0xFFD8C7B0).copy(alpha = 0.65f), // Bottom physical contour
        )
    )
}

Column(
    modifier = modifier
        .fillMaxWidth()
        // 1. Crisp, short micro-shadow (2dp contact, zero smudge)
        .shadow(
            elevation = 2.5.dp,
            shape = cardShape,
            clip = false,
            ambientColor = Color(0x182C2416),
            spotColor = Color(0x222C2416),
        )
        // 2. Multi-directional Specular Bevel Border
        .border(
            width = 1.dp,
            brush = borderBrush,
            shape = cardShape,
        )
        // 3. Convex Satin Gradient Face
        .background(
            brush = surfaceBrush,
            shape = cardShape,
        )
        .clickable(
            interactionSource = cardInteraction,
            indication = LocalIndication.current,
            onClick = onClick,
        )
        .pressScale(cardInteraction, 0.985f)
        .padding(horizontal = 16.dp, vertical = 14.dp)
)
