7大古典诗意主题双端背景设计工坊

每一个主题均配备两套独立渲染算法：App UI 纵向深远构图 vs 桌面 Widget 横向扁平聚景

双端量身定制 无缝契合小部件细线与留白
THEME 01
1. 满船清梦压星河
【App】天际微芒星汉与水面广袤波澜；【Widget】右下角收敛水纹与精致扁舟剪影。
黛蓝水波 孤舟剪影 星汉微芒
THEME 02
2. 清泉石上流
【App】清泉自上而下如绸缎般漫流；【Widget】底边平缓水溪与两枚温润苔绿卵石。
苔绿卵石 澄澈水纹 空山灵气
THEME 03
3. 长河落日圆
【App】半空升腾的圆润朱砂落日与起伏大漠；【Widget】右侧地平线沉降落日与横向金赭沙纹。
朱砂红日 金赭沙河 苍茫雄浑
THEME 04
4. 一行白鹭上青天
【App】群鹭自芦荡纵贯翱翔直上青天；【Widget】右上角紧凑排布3只轻盈白鹭掠过天际。
白鹭飞天 水墨芦苇 开阔高远
THEME 05
5. 疏影横斜水清浅
【App】主枝遒劲斜贯中部，朱砂花瓣点缀；【Widget】右边框优雅横向探入梅枝嫩芽，不遮挡数字。
水墨梅枝 朱砂梅瓣 暗香清韵
THEME 06
6. 古道西风瘦马
【App】蜿蜒盘旋的暮山古道与落霞；【Widget】右下角压低的山径折线与枯藤苍茫轮廓。
暮色山道 枯藤古树 深沉旷远
THEME 07
7. 斜风细雨不须归
【App】漫天斜风雨丝与江南青绿水岸；【Widget】右上垂柳嫩丝与右下青翠水波，线条轻灵。
斜风春雨 青绿山水 烟雨江南

1. 满船清梦压星河
